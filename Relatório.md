## 1. Objetivo

A Primeira Sprint teve o objetivo de desenvolver as funcionalidades essenciais e iniciais do sistema para a loja, como o cadastro de produtos, administradores e alunos.

## 2. O que foi realizado

- Cadastro de Alunos
- Vitrine da loja
- Cadastro de itens
- gerenciamento e alteração de alunos

## 3. O que falta implementar

- Implementação do cadastro de Administradores
- Inventário do usuário
- página de sugestões
- Ranking Global
- sistema de itens cosméticos
- Conversão de pontos acadêmicos

## 4. Problemas ocorridos

Durante o desenvolvimento, foi de grande dificuldade utilizar o github desktop para o merge de cada funcionalidade no main, estilização, e alguns erros em uma funcionalidade que afetava outras partes do site, criação de rotas e por qual parte começar a criação, além do problema que afetou o cadastro de administrador, o qual não foi para o main na primeira demonstração.

## 5. Lições Aprendidas

Percebemos a importância de dividir as tarefas e planejar melhor o que fazer primeiro para não se perder, como funciona o github desktop na criação de repositorios e branches, sempre rodar o código após alguma alteração no caso de algo que de erro em tudo.

## 6. Erros achados pelo Silktide

Os principais dos erros do silktide era por falta de uma sequência de HTML lógica de exibição, títulos de páginas estavam inadequados, ausentes ou vagos, contraste insuficiente sob as imagens ou fundo, além de elementos que o usuário não consegue desativar, não possuir titulo principal em uma pagina, contraste errado para texto e alguns campos não tem labels apropriados e um identificador com formato incorreto. ao todo, 9 erros de importância foram encontrados pelo silktide, sendo alguns deles que ocorreram pelo mesmo motivo e outros apenas em uma pagina específica.

## 7. Erros Corrigidos


Todos os erros, por não serem muito complicados, foram devidamente corrigidos e checados.
